# Changelog

## [0.1.0] - 2026-08-18

### Added

- Arabic-first RTL executive churn dashboard with seven operational views.
- Reproducible 12,000-record synthetic telecom dataset generator.
- Logistic Regression, Random Forest, and XGBoost comparison with population probability correction.
- SHAP global explainability and customer-level reason codes.
- Revenue at Risk, 30/60/90-day risk, and Retention Priority Score.
- FastAPI contracts, role-based demo controls, customer ID masking, audit logging, and CSV export.
- PostgreSQL and Docker Compose runtime with same-origin Nginx proxying.

### Security

- Added strict request validation, security headers, allowlisted export fields, and non-root backend container.
